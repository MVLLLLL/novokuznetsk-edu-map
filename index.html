Рейтинг районов по доступности УДО

Данный проект направлен на анализ географической доступности учреждений дополнительного образования (УДО) для школьников города Новокузнецка.

Цель

Определить, какие школы находятся вне 3-километровой зоны от ближайшего УДО, чтобы выявить «образовательные пустыни» и предложить меры по улучшению доступности.

Методология

  • Использованы открытые данные по школам России и УДО Кемеровской области.
  • Фильтрация объектов по координатам, принадлежащим Новокузнецку.
  • Расчёт расстояний по формуле Хаверсина.
  • Визуализация на интерактивной карте с цветовой дифференциацией.

Практическая польза

Результаты могут быть использованы администрацией города для планирования новых УДО, организации транспорта или мобильных кружков в отдалённых районах.
