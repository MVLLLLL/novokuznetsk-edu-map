# Принцип работы программы "Образовательная карта Новокузнецка"

## Общее описание

Программа представляет собой веб-приложение для анализа географической доступности учреждений дополнительного образования (УДО) для школьников Новокузнецка. Система автоматически определяет школы, находящиеся вне зоны пешеходной доступности от УДО.

## Архитектура системы

### 1. Компоненты приложения

```
Образовательная карта Новокузнецка

└── Data Storage (хранение данных)
```

### Этап 2: Расчет доступности

**Алгоритм формулы Хаверсина:**
```javascript
function haversine(lat1, lon1, lat2, lon2) {
    const R = 6371; // Радиус Земли в км
    const dLat = (lat2 - lat1) * Math.PI / 180;
    const dLon = (lon2 - lon1) * Math.PI / 180;
    
    const a = Math.sin(dLat/2) * Math.sin(dLat/2) +
              Math.cos(lat1 * Math.PI / 180) * 
              Math.cos(lat2 * Math.PI / 180) *
              Math.sin(dLon/2) * Math.sin(dLon/2);
    
    const c = 2 * Math.atan2(Math.sqrt(a), Math.sqrt(1-a));
    return R * c; // Расстояние в километрах
}
```

**Процесс классификации школ:**
```
Для каждой школы в списке:
  1. Инициализировать флаг inRadius = false
  2. Для каждого УДО в списке:
      - Рассчитать расстояние по формуле Хаверсина
      - Если расстояние ≤ 3 км:
          * Пометить школу как "в зоне доступности"
          * Прервать проверку для этой школы
  3. Если ни одно УДО не найдено в радиусе 3 км:
      - Поместить школу в список "вне зоны доступности"
```

### Этап 3: Визуализация на карте

**Цветовая схема маркеров:**
- 🔵 **Синий** (УДО): `#6366f1` - учреждения дополнительного образования
- 🟢 **Зеленый** (в зоне): `#10b981` - школы с доступом к УДО
- 🔴 **Красный** (вне зоны): `#ef4444` - школы без доступа к УДО

**Типы маркеров:**
- УДО: кружки радиусом 9px с белой обводкой
- Школы: кружки радиусом 7px с белой обводкой

## Бизнес-логика

### Определение принадлежности к району

```javascript
function getDistrict(lat, lon) {
    // Географические границы районов Новокузнецка
    const districts = {
        "Куйбышевский": { minLat: 53.78, maxLat: 53.85, minLon: 86.95, maxLon: 87.25 },
        "Новоильинский": { minLat: 53.75, maxLon: 53.82, minLon: 87.10, maxLon: 87.35 },
        // ... другие районы
    };
    
    // Проверка принадлежности к каждому району
    for (const [name, bounds] of Object.entries(districts)) {
        if (lat >= bounds.minLat && lat <= bounds.maxLat &&
            lon >= bounds.minLon && lon <= bounds.maxLon) {
            return name;
        }
    }
    
    return "Другой";
}
```

## Требования к данным

### Входные данные:
- Координаты в десятичных градусах (WGS84)
- UTF-8 кодировка для текстовых данных
- Разделитель полей: точка с запятой
- Обязательные поля: название, адрес, широта, долгота

### Выходные данные:
- Интерактивная карта с цветовой кодировкой
- Статистические показатели
- Рейтинг районов
- Визуализация "образовательных пустынь"

Этот принцип работы обеспечивает точный анализ доступности образования и предоставляет городским властям инструмент для принятия обоснованных решений по развитию образовательной инфраструктуры.
