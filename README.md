# Образовательная карта Новокузнецка

Интерактивная карта для анализа доступности учреждений дополнительного образования (УДО) для школьников города Новокузнецка.

🔗 **Демо**: [(https://github.com/MVLLLLL/novokuznetsk-edu-map/)] (https://github.com/MVLLLLL/novokuznetsk-edu-map/)

## Возможности
- Визуализация УДО и школ на карте
- Выделение школ вне 3-км зоны доступности
- Рейтинг районов по обеспеченности УДО
- Маршруты до ближайших центров

## Используемые данные
- Реестр школ России (Минпросвещение)
- Открытые данные УДО Кемеровской области

## Технологии
- HTML5, CSS3, JavaScript
- Leaflet.js
- Формула Хаверсина для расчёта расстояний

> Проект создан в рамках соревнования по спортивному продуктовому программированию.
